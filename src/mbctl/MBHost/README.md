# MBHost

MBHost 可以指本地Host也可以指远程Host，目前MBHost只支持“运行mbctl工具的本地Host“运行，未来会扩展功能支持远程主机。

目前的推荐运行方法指的就是mbctl安装在服务器上，然后在服务器中执行mbctl命令管理服务器。

所谓本地远程，区分的就是 mbctl 在哪里读取配置文件、怎样执行Host命令以及怎样执行nerdctl命令。这三种方法可以任意的组合，
比如mbctl可以读取本地配置文件，执行远程的Host命令并执行本地的nerdctl命令来操纵远程的containerd，这样是最理想的本地远程分开的操作。

但是实际情况非常复杂和困难，这种理想远程控制的成本过高，我们实际上没有必要这么做。其实只需要远程主机可以执行 mbctl 即可。

未来可能会支持本地配置文件+远程服务器+远程主机，不过那肯定是大后期要做的工作了。
